# F1 Forecast desktop app

The original portfolio demo is preserved in commit `1ed7598` (`app/page.tsx`). Its interactive Title, Top 3, and Top 5 probability leaderboard is restored inside the gray macOS desktop, using the existing window manager. It is not an iframe or a redirect to the project case study.

Launch from the desktop, Dock, Apps menu, or Spotlight. The app is a singleton: launching again focuses/restores its window. Close, minimize, drag, resize, snap, full screen, Mission Control, Show Desktop, and desktop/Dock context menus use the shared desktop behavior. It does not open on startup and does not add terminal commands or alter the vinyl project interaction.

## Data provenance

- `app/data/f1-standings.json`: official 2026 constructor standings checked September 7, 2026, through the Italian Grand Prix on September 6 (13 completed Grands Prix, 5 Sprints). The current calendar lists 23 Grands Prix. References are embedded with the snapshot.
- `app/data/f1-forecast.json`: September 7 in-season v2 export through the Italian Grand Prix, generated by `refresh_forecast.py` in brianbzeng/f1model. This reconstructs the missing pipeline rather than relabeling the July export. Ridge alpha 10, expanding-window season validation, 10,000 seeded residual simulations. Historical 2018 is excluded because the original CSV merges distinct Force India entries. Full methodology and exact input snapshot are in the model repository.
- Forecast and standings now cover the same completed race. Current points come from official standings; probability and mean-rank fields come from the regenerated model. The Standings control sorts by current points. Race-only features exclude Sprint points consistently; official final targets and displayed championship points include them.
- `app/data/f1-driver-leader.json`: official driver leader snapshot for the half-width square widget. The widget is right-aligned, and each glass card clips its own blur/shadow so gaps reveal the wallpaper.

Official references: [constructor standings](https://www.formula1.com/en/results/2026/team), [race results](https://www.formula1.com/en/results/2026/races), [calendar](https://www.formula1.com/en/racing/2026). Historical model repository: [brianbzeng/f1model](https://github.com/brianbzeng/f1model).

No automatic scraping, polling, scheduled updates, dependencies, or paid services were added. Updates remain a deliberate local data refresh, with the displayed dates making the snapshot's age clear.
