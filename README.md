# Brian Zeng — Portfolio

A one-page portfolio hub for Brian Zeng's data products and modeling work.

The site features the live NBA Odds Predictor and TTB Label Review Assistant,
an interactive F1 constructor scenario explorer, and an Amazon review-risk case
study. It is built with React, TypeScript, vinext, and CSS.

## Local development

Requires Node.js 22.13 or newer and pnpm.

```bash
pnpm install
pnpm dev
pnpm build
```

The main page lives in `app/page.tsx`; the visual system and responsive styles
live in `app/globals.css`.
